# 供应商报价单 - 外部（无价格）

> 注：Print Format 在系统中的名称仍为「供应商报价单 - 外部（无价格）」；语义为**价税格留空**，非删除列。

Supplier Quotation 的外部版变体：表格结构与「供应商报价单 - 外部」相同（含单价、金额、小计、税费行、总计、大写），但**不打印系统内已保存的单价与金额**，相关单元格始终留空，供供应商手填。

## 与「供应商报价单 - 外部」差异

| 项目 | 外部 | 本格式 |
|------|------|--------|
| 单价、金额列 | 系统有单价则带出格式化数值，否则留空 | **始终留空** |
| 汇总区 | 有合计则显示，否则留空 | **始终留空**（税费行保留说明列，金额格留空） |

物料信息、数量、单位、备注及抬头与外部版一致。

## 同步到站点

```bash
bench --site <site> execute cos.scripts.sync_supplier_quotation_external_no_price.sync
```
