# 物料移动打印格式（Stock Entry）

与「物料需求 - 标准」版式对齐，字段与逻辑对齐 `stock-entry-standard`（移库单专用模板）。

## 与旧版差异摘要

- **基本信息**：移库单号、过账日期、移库类型、项目；增加 **公司**、**过账时间**；关联来源优先主表（工单/BOM/采购订单/物料需求），再回落子表首行。
- **项目**：主表 `project` → 子表首行 `project` → 主表/子表工单反查 `Work Order.project`。
- **明细**：使用 Stock Entry 子表字段 **源仓库 / 目标仓库 / 批次与序列号**（不再使用 MR 的单一仓库与需求日期列）。
- **签名**：制单人（用户全名）、发货人(源)、收货人(目标)、审核/监管。
